## RESUMEN DEL PROYECTO
Juego 2048 personalizado para la Universidad EAN.
Funciona completamente en el navegador (frontend puro).
Guarda y consulta puntajes globales mediante una API serverless en AWS.
Diseñado responsive: funciona en móvil (swipe táctil) y PC (teclado + mouse).
Tiene un personaje llamado "Meli" (SVG) que actúa como guía visual.

---

## ARQUITECTURA GENERAL

  [Usuario / Navegador]
        │
        ▼
  [AWS Amplify]  ← sirve los archivos estáticos (HTML/CSS/JS)
        │  entry point: index.html
        ▼
  [API Gateway]  ← HTTP API
        │  POST /scores             → guardar puntaje
        │  GET  /scores/top?limit=N → leer Top N puntajes
        ▼
  [AWS Lambda]   ← Node.js 22.x, dos funciones
        │  postScore     → recibe {nombre, puntaje}, genera id, inserta en DynamoDB
        │  getTopScores  → escanea DynamoDB, ordena desc, devuelve top N
        ▼
  [DynamoDB]     ← tabla "Scores2048"
        │  Partition key: id (string / timestamp)
        │  Atributos: nombre (string), puntaje (number), fecha (string ISO)

### juego.js  ⚠️ CONTIENE URL DE AWS — NO CAMBIAR SIN COORDINAR
  Archivo más grande e importante del proyecto.
  Estructura interna:

  CONSTANTES GLOBALES:
    TAM = 4                        (tamaño del tablero)
    CLAVE_ESTADO = '2048_ean_estado'
    CLAVE_MEJOR  = '2048_ean_mejor'
    CLAVE_HISTORIAL = '2048_scores' (fallback local, no usado activamente)

  FILTRO DE NOMBRES (líneas ~12-64):
    PALABRAS_PROHIBIDAS → array con palabras bloqueadas (español, colombia, inglés)
    limpiarTexto(texto) → normaliza acentos, leet speak, símbolos especiales
    esNombreInapropiado(nombre) → retorna true si contiene palabras bloqueadas
    solicitarNombreValido() → prompt con hasta 3 intentos, fallback "JugadorN"

  AWS API (líneas ~68-85):
    API_BASE = "https://9g0v6cib0g.execute-api.us-east-1.amazonaws.com"
    apiGuardarPuntajeAWS({nombre, puntaje}) → POST /scores
    apiObtenerTopAWS(limit=5) → GET /scores/top?limit=N

  UTILIDADES (líneas ~88-93):
    copiarMatriz(m)  → deep copy de la matriz 4x4
    matrizVacia()    → crea matriz 4x4 llena de 0
    limitar(v,min,max) → clamp numérico
    generarId()      → string único basado en timestamp

  CLASE Juego2048:

    constructor():
      Estado: tablero (4x4), puntaje, mejor, ganado, terminado,
              perdidoTemporal, historial[], maxDeshacer=6,
              sonidoActivo=true, continuarDespuesVictoria=false
      Referencias DOM: domTablero, domPuntaje, domMejor, domFichas,
                       domFin, domPuntajeFinal, botonDeshacer,
                       listaScores, btnVerMas
      Llama: iniciar()

    iniciar():
      1. iniciarAudio() → crea AudioContext
      2. configurarUI() → crea celdas DOM + overlay fin + slider
      3. configurarEventos() → teclado + touch + botones
      4. cargar() || nuevo() → restaura estado o crea partida nueva
      5. actualizarVista() → renderiza tablero
      6. cargarHistorialMiniScore() → carga Top 5 desde AWS

    configurarEventos():
      Teclado:
        Ctrl+Z / R / Delete → deshacer()
        Ctrl+R → reiniciar()
        Flechas / WASD → mover(dir)
        Espacio → confirm + reiniciar()
        Escape → cerrar overlay si aplica
        M → toggleSonido()
      Touch:
        touchstart / touchend en domTablero
        umbral dinámico: max(20, min(innerWidth*0.04, 40))
        detecta swipe en 4 direcciones → mover(dir)
      Botones:
        #btn-deshacer → deshacer()
        #btn-reiniciar → reiniciar()
        #btn-continuar → deshacer() (si perdidoTemporal) | continuar (si ganado)
        #btn-reiniciar2 → finalizar partida | nuevo juego
        #btn-ver-mas → toggle mostrandoTodo + renderMiniScore()
      Ventana:
        beforeunload → guardar()

    configurarUI():
      Crea 16 .celda dentro de domTablero
      Crea overlay #fin-juego con modal-victoria (innerHTML)
      Re-asigna domFin y domPuntajeFinal
      Configura slider #rango-deshacer con listener input

    guardarEstado():
      Push {tablero, puntaje} al historial[]
      Limita historial a maxDeshacer entradas (shift si excede)

    deshacer():
      Pop del historial
      Restaura tablero y puntaje previos
      Resetea ganado, terminado, perdidoTemporal a false
      Oculta overlay, actualiza vista y botones, guarda, suena (200Hz)

    nuevo():
      Resetea todo el estado
      Llama agregarFicha() dos veces para comenzar

    reiniciar():
      Si puntaje > 0: confirm() + agregarAlHistorial()
      Llama nuevo(), actualizarVista(), ocultarFin(), guardar()

    mover(dir):
      Si perdidoTemporal: return (bloquea movimientos)
      guardarEstado()
      Procesa cada fila/columna según dirección (izq/der/arr/aba):
        1. Extrae línea según dirección
        2. Filtra ceros → compacta
        3. Fusiona adyacentes iguales (× 2, suma a puntaje)
        4. Rellena con ceros hasta TAM
        5. Escribe de vuelta al tablero
      Si no movió: pop historial, return
      agregarFicha() → agrega ficha 2 (90%) o 4 (10%)
      Actualiza mejor en localStorage si corresponde
      suena (300Hz)
      actualizarVista(), actualizarBotones(), guardar(), verificarEstado()
      setTimeout 30ms: busca .ficha-inner.vN y agrega clase .fusion

    verificarEstado():
      Si hay 2048 y no continuarDespuesVictoria y no ganado:
        → ganado = true, setTimeout 300ms → mostrarFin()
      Si esFin():
        → perdidoTemporal = true, setTimeout 300ms → mostrarFin()

    esFin():
      Retorna true si: ninguna celda vacía Y ningún par adyacente igual

    mostrarFin():
      Adapta texto del overlay según estado:
        ganado → "¡Llegaste a 2048!" + botones Continuar/Reiniciar
        perdidoTemporal → "¡Sin movimientos!" + botones Deshacer/Finalizar
        terminado → "¡Fin del juego!" + botón Nueva partida
      Agrega clase .mostrar a domFin

    ocultarFin():
      Quita clase .mostrar de domFin

    actualizarVista():
      Calcula lado = (tamTab - gap*(TAM+1)) / TAM
      Mapea fichas DOM actuales por dataset.pos ("r-c")
      Para cada celda del tablero lógico:
        v===0 → elimina DOM si existe
        v!==0 → busca ficha en posición exacta, o reutiliza una con mismo valor,
                o crea nueva con crearFicha()
        Posiciona con: ficha.style.transform = `translate(${x}px, ${y}px)`
      Elimina fichas DOM sobrantes (merges)
      Actualiza puntaje, mejor, fichas en DOM
      Aplica clase alerta14/15/16 según totalFichas

    crearFicha(valor, fila, col):
      Crea div.ficha con div.ficha-inner.vN dentro
      Posiciona con transform
      Animación de entrada: inner scale 0.8→1 + opacity 0→1
      Agrega al domTablero

    agregarAlHistorial(puntos):
      Llama solicitarNombreValido() → prompt con filtro
      apiGuardarPuntajeAWS({nombre, puntaje})
        .then → cargarHistorialMiniScore()
        .catch → console.error

    cargarHistorialMiniScore():
      apiObtenerTopAWS(5)
        .then → datosMiniScore = [{nombre, puntaje}...], renderMiniScore()
        .catch → datosMiniScore = [], renderMiniScore()

    renderMiniScore():
      Limpia #lista-scores
      Renderiza items según mostrandoTodo (5 o 10)
      Muestra/oculta #btn-ver-mas si hay más de 5

    sonido(freq, dur):
      Crea OscillatorNode + GainNode en AudioContext
      Tono sinusoidal con envelope exponencial

    guardar():
      JSON.stringify del estado completo → localStorage CLAVE_ESTADO

    cargar():
      JSON.parse de localStorage CLAVE_ESTADO
      Restaura tablero, puntaje, mejor, historial, perdidoTemporal,
      maxDeshacer, sonidoActivo

  INICIALIZACIÓN (fin del archivo):
    DOMContentLoaded → juego = new Juego2048()

  MELI SWITCH (fuera de la clase):
    #meliSwitch click → toggle .brillante + cambia #textoInstrucciones
    Mensaje 1: "Junta las fichas..." (instrucción básica)
    Mensaje 2: "Mueve las fichas con WASD..." (instrucción de controles)

### backend/aws-config.md
  Documentación de configuración de AWS:
    - DynamoDB: tabla Scores2048, partition key id, capacidad on-demand
    - Lambda postScore: runtime Node.js 22.x, handler index.handler,
      env TABLE_NAME=Scores2048, recibe {nombre, puntaje}, genera id timestamp
    - Lambda getTopScores: misma config, escanea y ordena por puntaje desc
    - API Gateway: HTTP API, stage $default, CORS *, rutas POST/GET

### backend/lambda/postScore/index.mjs
  Lambda para guardar puntaje.
  Endpoint: POST /scores
  Body esperado: { nombre: string, puntaje: number }
  Genera: id = Date.now().toString()
  Inserta en DynamoDB: { id, nombre, puntaje, fecha: new Date().toISOString() }

### backend/lambda/getTopScores/index.mjs
  Lambda para consultar ranking.
  Endpoint: GET /scores/top?limit=N (default 5)
  Escanea tabla Scores2048
  Ordena resultados por puntaje descendente
  Retorna los primeros N registros

## NOTAS PARA FUSIÓN CON OTRO PROYECTO
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  1. Los 3 HTML están en raíz → mover a subcarpeta /juego/ si el otro proyecto
     necesita la raíz, actualizando los href de navegación entre páginas.

  2. El CSS usa clases muy específicas del juego (.contenedor-juego, .tablero-juego,
     .ficha, etc.) → bajo riesgo de colisión con frameworks externos.
     Si el otro proyecto usa Bootstrap u otro framework, cargar estos CSS DESPUÉS.

  3. El único estado persistente en cliente es localStorage con prefijo '2048_ean_'
     → sin riesgo de colisión con otras claves del localStorage.

  4. La API AWS está en una sola constante (API_BASE en juego.js) → fácil de
     apuntar a otro endpoint o envolver en un archivo de config.

  5. Las imágenes Meli son SVG → escalables sin pérdida. Mover a /juego/img/ si
     se reorganiza el proyecto.

  6. js/ui.js es el punto de extensión → agregar helpers compartidos ahí.

  7. colores.html es completamente independiente → se puede borrar sin efecto.

  8. La clase .tutorial-desktop en <body> es el toggle de layout → cuidar que
     no colisione con clases globales del otro proyecto.
